## 🚀 What is Monarch OS?  
Monarch OS is a GNU/Linux distribution derived from the Omarchy project and inspired by SkillArch, focused on delivering a powerful system for Security Professionals. Our goal is to make a modular, up-to-date, community-driven OS that help pentesters and bug hunters everyday.

---

## 📂 Our Repositories  
Here’s a quick overview of the key repositories in this organization:  

- **[monarch-iso](https://github.com/monarch-os/monarch-iso)** — (Shell) Tools, scripts and resources to build the ISO images of Monarch OS.
- **[monarch-pkgs](https://github.com/monarch-os/monarch-pkgs)** — (Shell) Custom package definitions, overlays, and build-scripts for the package ecosystem.  
- **[monarch](https://github.com/monarch-os/monarch)** — (Shell) Core system configuration, boot scripts, and system-level integration for Monarch OS.  
- **[monarch-os.github.io](https://github.com/monarch-os/monarch-os.github.io)** — (HTML) The website and documentation portal for Monarch OS.

## 🔧 Getting Started  
Interested in trying out Monarch OS or contributing? Here’s how to get going:

1. Visit the [website](https://monarchlinux.com) and download the Beta ISO image (build from `monarch-iso`).  
2. Boot from the ISO, install Monarch OS, start your journey.  
3. Explore the system, check out the documentation.  
4. If you’d like to contribute:  
   - Browse issues or feature requests in any of the repos.  
   - Fork the repository, create your branch, and submit a pull request.  
   - Review our contributing guidelines in the repo.  
5. Connect with the community for help, suggestions or collaboration (Discord/Forum links forthcoming).
